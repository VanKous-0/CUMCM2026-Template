\section{模型建立与求解}
\subsection{数据标准化}
对效益型指标，使用极差变换：
\begin{equation}
  z_{ij}=\frac{x_{ij}-\min_i x_{ij}}{\max_i x_{ij}-\min_i x_{ij}}.
\end{equation}
对于成本型指标，可将分子改为 $\max_i x_{ij}-x_{ij}$。若极差为零，应在程序中作单独处理。

\subsection{综合评价模型}
令 $w_j$ 为指标权重，则对象 $i$ 的综合得分为
\begin{equation}
  S_i=\sum_{j=1}^{m}w_jz_{ij}, \qquad \sum_{j=1}^{m}w_j=1,\quad w_j\geq 0.
\end{equation}
权重可由题设、熵权法、层次分析法或其他适当方法确定。这里仅演示论文排版；实际参赛论文
应完整说明权重来源、求解过程和结果解释。

def score(normalized_data, weights):
    """Return weighted scores for each row of normalized_data."""
    return [sum(value * weight for value, weight in zip(row, weights))
            for row in normalized_data]
